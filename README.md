# Flight Path and Time Calculator

A lightweight Java command-line application that calculates the straight-line flight distance and total travel time for an object or drone moving across horizontal and vertical coordinates.

## 🚀 Features

* **Euclidean Distance Calculation:** Uses the Pythagorean theorem (`Math.sqrt()` and `Math.pow()`) to determine the exact 2D flight path distance from horizontal and vertical components.
* **Flight Time Estimation:** Computes the precise duration of travel based on a user-defined average speed.
* **Formatted Outputs:** Clean console presentation showing rounded distances and precise time durations using `System.out.printf()`.
